# requirements.txt
#
# This file is a pip-installable snapshot of the dependencies declared in
# `pyproject.toml`. `pyproject.toml` (+ `poetry.lock`, once generated) is the
# SOURCE OF TRUTH for this project — Poetry is what `Dockerfile` uses to
# build the image. This file exists only for tooling/CI that installs via
# plain `pip install -r requirements.txt` instead of Poetry.
#
# Regenerate after any dependency change with:
#   poetry export -f requirements.txt --output requirements.txt --extras all --without dev
#
# Includes every optional extra (matches the Dockerfile's default
# `INSTALL_EXTRAS=all`), so every extractor/embedder/reranker backend works
# out of the box: OCR (pdf2image/pytesseract), PDF (pypdf/pdfplumber), HTML
# (beautifulsoup4/lxml/trafilatura), DOCX (python-docx), embeddings
# (openai/sentence-transformers/cohere), and exact token counting (tiktoken).
